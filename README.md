# Ninnah Errands & Jewellery Website

A colorful, functional single-page website for Ninnah's errands and jewellery business.

## Features

- **Jewellery & fashion** product categories with WhatsApp inquiry links
- **Errand services** listing with all services from the flyer
- **M-Pesa payment** section with copy-to-clipboard for Till & Account numbers
- **Booking form** that opens WhatsApp with a pre-filled message
- **Contact info**: phone, location (Mwembe Tayari CBD), business hours
- **Floating WhatsApp button** for quick access
- Fully responsive mobile design

## Run Locally

Open `index.html` in a browser, or serve with any static server:

```bash
npx serve .
```
